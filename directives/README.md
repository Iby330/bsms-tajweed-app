# Directives

This directory contains Standard Operating Procedures (SOPs) written in Markdown.

## Purpose
- Define goals, inputs, tools/scripts to use, outputs, and edge cases
- Written in natural language, like instructions for a mid-level employee
- Living documents that get updated as the system learns

## Format
Each directive should include:
- **Goal**: What needs to be accomplished
- **Inputs**: What data/parameters are needed
- **Tools**: Which execution scripts to use
- **Outputs**: What the result should look like
- **Edge Cases**: Common errors, API limits, timing considerations

## Examples
- `scrape_website.md` - Instructions for web scraping tasks
- `process_data.md` - Data transformation workflows
- `api_integration.md` - Third-party API interaction patterns
